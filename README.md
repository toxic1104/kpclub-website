# KP Club Website

A responsive website for KP Club, a basketball training club in Padma Nagar, Karnik Nagar, Solapur.

**Live site:** https://kpclub-basketball.netlify.app

## What it includes
- Hero section, stats strip and club introduction
- Trainer profiles and daily training schedule (Mon-Sat, 6-8 PM)
- Matches, summer camp and other activities sections
- Embedded Google Map of the ground
- Contact section with one-tap WhatsApp and call buttons
- Mobile-friendly layout with a sticky navigation bar

## Tech stack
- HTML5, CSS3 (Flexbox, responsive media queries)
- Hosted on Netlify (free tier)
- Source code on GitHub

## Design
Dark red and black theme with bold typography, inspired by sports-brand landing pages.

## Why a static site?
The club needs people to find its location, timings and contact details. A static site does this with no server to maintain, no database to pause and no hosting cost.
